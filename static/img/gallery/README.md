# Drop gallery photos in this folder

Any image you place here is shown automatically on the **Gallery** page
(`/gallery`) — no code changes needed.

- Supported types: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`
- Photos are shown sorted by file name (e.g. prefix `01-`, `02-` to order them).
- The file name becomes the caption: `kumkum-society-lobby.jpg` → "Kumkum Society Lobby".
